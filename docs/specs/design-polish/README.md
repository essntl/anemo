# Design polish: before and after

Playwright (Edge) against a local dev stack with the fake model, 1440 px and 390 px, light and dark.
Every screen in both widths and themes is in `before/` and `after/` (same file names);
the table shows a selection. Background: the Aurora gradient, a blue tint and frosted glass,
so the setting rows that fold open are open.
